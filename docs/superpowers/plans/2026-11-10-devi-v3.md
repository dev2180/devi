# Devi v3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add chants (fade-in, pairing with pictures, background media notification), the redesigned
crimson-and-gold screens with animated how-to demos, the theme-following Devi-eyes icon, a restart
greeting, and closing on calls and notifications.

**Architecture:** Platform-only Kotlin, as in v1/v2, with no new libraries.
- Pure logic lives in small JVM-tested files: `FadeCurve`, `ChantStore`, `Pairings`,
  `DemoTimeline`, `RestartGreeting`, `InterruptPolicy` and `VolumeKeyPolicy`.
- `ChantService` is a `mediaPlayback` foreground service with `MediaPlayer` and a `MediaSession`.
- The UI is two activities: `ManageActivity` (home) and `ShortcutsActivity`, plus a custom
  `HowToDemoView` drawn on Canvas.

**Tech Stack:** Kotlin 2.0.21, AGP 8.13.2, compileSdk/targetSdk 36, minSdk 31, JUnit 4.13.2.
- Builds run with `JAVA_HOME=~/.jdks/jbr-21.0.11`.
- Build output goes to `~/.devi-build`.

**Spec:** `docs/superpowers/specs/2026-11-10-devi-v3-design.md`. Its "Final decisions" section wins.
The visual reference is `design/mockup/index.html` + `page.css`.

## Global Constraints
- **Colours** (in `res/values/colors.xml`, never inline):

  | Token | Value |
  | --- | --- |
  | ground | `#3A0E10` (Kiln reduction ≈ oklch 21% 0.06 22) |
  | ground-2 | `#46141A` |
  | ground-3 | `#55191F` |
  | ink | `#F4ECDD` |
  | ink-2 | `#E3D5BF` |
  | muted | `#C9B49A` |
  | rule | `#24F4ECDD` |
  | accent (gold) | `#F0C46A` |
  | accent-ink | `#2A0C0E` |
  | void | `#0B0606` |

- **Gold appears only on:** the live chant, the primary button, "on" switches and the main picture.
- **Fonts:** Boska 500 for display, Geist 400/500 for body, bundled in `res/font/`. Labels are
  sentence case and untracked. No emoji icons. No middle-dot-joined strings.
- **Radii:** 28 dp on pictures, 16 dp on wells, 999 dp on pills.
- **Reduced motion:** if `Settings.Global.ANIMATOR_DURATION_SCALE` is 0, every animation shows a
  still frame.
- **Chant fades:** fade-in 10 000 ms, fade-out 1 500 ms, equal-power. A chant never goes above the
  phone's media volume (gain ≤ 1.0).
- **Chants are never in the APK.** Files from `devi/chants/` are only pushed to `/sdcard/Music/Devi/`.
- **No ghunghroo, no flute.**
- **Permissions to add:**
  - `POST_NOTIFICATIONS`, asked at the first play;
  - `FOREGROUND_SERVICE`;
  - `FOREGROUND_SERVICE_MEDIA_PLAYBACK`.

  Still no `INTERNET`.
- **Restart greeting:** off by default. It fires once per boot, only if the service connects within
  180 000 ms of boot.

## Review Focus
1. **A call, an alarm or other audio takes focus mid-chant.** The chant pauses (transient loss) or
   stops (permanent loss) and never plays over the call. Test: `InterruptPolicyTest.callAlwaysCloses`
   (Task 3). The focus handling itself is a manual check in Task 7.
2. **A chant file is missing or undecodable.** Play is skipped and a message shows, with no crash.
   Test: `ChantStoreTest.failedCopyLeavesNothing` (Task 1). `MediaPlayer` errors are caught in Task 4.
3. **The viewer closes while a fade-in is under way.** The fade-out starts from the current gain,
   with no jump. Test: `FadeCurveTest.fadeOutFromCurrentGain` (Task 1).
4. **A paired chant or picture is removed.** Its pairing is cleared. Tests:
   `PairingsTest.removingChantClearsPairs` and `removingImageClearsPair` (Task 1).
5. **The notification permission is denied.** Playback still works, because the foreground service
   runs and only its notification is hidden. Manual check, Task 7.

### Task 1: Chant data and fades (pure, JVM-tested)
**Files:** create `FadeCurve.kt`, `ChantStore.kt` and `Pairings.kt` in `app/src/main/java/com/devi/overlay/`,

**Interfaces (produces):**
- `object FadeCurve`:
  - `fun fadeIn(elapsedMs: Long, durationMs: Long = 10_000): Float`, which is `sin(t·π/2)`, clamped
    to 0..1;
  - `fun fadeOut(elapsedMs: Long, fromGain: Float, durationMs: Long = 1_500): Float`, which is
    `fromGain·cos(t·π/2)`.
- `class ChantStore(dir: File)`:
  - `ids(): List<String>`
  - `add(input: InputStream, ext: String, title: String): String`
  - `remove(id: String)`
  - `title(id: String): String`
  - `file(id: String): File`
  - `companion forContext(ctx)` → `filesDir/chants`

  Order is kept in `order.txt` and titles in `titles.txt` as `id\ttitle`. Copies use temp
  file + rename, exactly like `ImageStore`.
- `class Pairings(dir: File)`:
  - `chantFor(imageId: String): String?`
  - `pair(imageId: String, chantId: String?)`
  - `forgetChant(chantId: String)`
  - `forgetImage(imageId: String)`

  Pairs are stored in `pairs.txt` as `imageId=chantId`.

### Task 4: ChantService and viewer wiring
**Files:**
- create `ChantService.kt`;
- modify `ViewerActivity.kt`, `DeviAccessibilityService.kt` and `AndroidManifest.xml`;
- in `DeviSettings.kt`, add `restartGreeting` and `lastGreetedBootCount`.

**Interfaces (produces):**
- `ChantService.play(ctx, chantId: String, startedByViewer: Boolean)`
- `ChantService.stop(ctx, fade: Boolean = true)`
- `ChantService.pauseOrResume(ctx)`
- `@Volatile ChantService.isPlaying: Boolean`
- `ChantService.currentChantId: String?`
- `ChantService.startedByViewer: Boolean`

**Service:**
- It is a foreground service with `foregroundServiceType="mediaPlayback"`.
- It runs a `MediaPlayer` on `USAGE_MEDIA` / `CONTENT_TYPE_MUSIC` and requests `AUDIOFOCUS_GAIN`.
  It pauses on a transient loss, stops on a permanent loss, and resumes on gain only if it was
  paused by the loss.
- A gain tick of 50 ms uses `FadeCurve`. A new play while playing crossfades: the old player fades
  out while the new one fades in.
- It shows a `Notification.MediaStyle` with a `MediaSession` token: the title, play/pause and stop.
  The channel is "Chants", importance low.
- `onError` → stop, and a toast saying "This chant can't be played".

**Viewer:**
- On open, and on each swipe, it looks up `Pairings.chantFor(id)`. If there is a pairing, it calls
  `ChantService.play(..., startedByViewer = true)`. If there isn't, and the viewer started the
  current chant, it stops it with a fade.
- On finish, if `startedByViewer`, it calls `stop(fade = true)`.

**Accessibility service:**
- It adds `typeNotificationStateChanged` to `accessibility_config.xml`.
- A notification event, or a window from a package containing `incallui`/`dialer`/`telecom`, or the
  audio mode leaving NORMAL (`AudioManager.addOnModeChangedListener`), calls
  `InterruptPolicy.shouldClose`. If that is true, it sends `ViewerActivity.ACTION_CLOSE` (a local
  broadcast to the viewer, which finishes).
- It passes `chantPlaying = ChantService.isPlaying` to `VolumeKeyPolicy`.
- `onServiceConnected` reads `Settings.Global.BOOT_COUNT` and `SystemClock.elapsedRealtime()`. If
  `RestartGreeting.shouldGreet(...)`, it opens the viewer and saves the boot count.

- [ ] **Step 2:** Run `./gradlew :app:testDebugUnitTest :app:assembleDebug`. Expected: BUILD

### Task 5: Visual system and the HowToDemoView

  ground colour, no action bar) and `res/font/` (Boska + Geist);

**Fonts:**
- Boska: Fontshare zip `https://api.fontshare.com/v2/fonts/download/boska`, using `Boska-Medium`.
- Geist: from `https://github.com/vercel/geist-font/releases` (or Google Fonts static), using

- Put the licence text files in `app/src/main/assets/licenses/`.

**`HowToDemoView`:**
- `var mode: DemoMode`, `var keys: List<VolumeKey>`, `var active: Boolean`.
- It draws the mockup's phone: rim, body, glass, camera, three buttons, with the pressed one offset
  2 dp toward the body and filled gold.
- Her picture is `ImageStore.main()`, decoded once to the glass size.
- It draws the wake overlay, the thumb (three paths from the mockup SVG: skin, shade, nail, plus a
  shadow ellipse), the ripple ring and the chips (lit = gold outline and gold label).
- It scales the 160×210 design box to the view.
- A `ValueAnimator` runs over `LOOP_MS` and is `INFINITE` while `active` and attached. When
  inactive it shows a dimmed still frame at 4000 ms. Reduced motion → a still frame.
